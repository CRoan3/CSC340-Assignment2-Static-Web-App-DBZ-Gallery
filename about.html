About This Website

This website is a static character gallery based on the Dragon Ball universe. I chose to use Dragon Ball because it has a large cast of fun, memorable characters with very different personalities, abilities, backgrounds, and roles.

This gallery currently only includes Goku, Vegeta, Krillin, Bulma, and Chi-Chi.

The design uses a dark background with orange and blue accents, primarily inspired by colors commonly associated with Dragon Ball. The character cards are arranged in a responsive grid so that the page remains organized on different screen sizes (mobile vs desktop).

This website was built entirely using plain HTML and CSS. The search bar and character submission form are only visual elements and do not currently filter or process data.
