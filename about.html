About This Website

This website is a static character gallery based on the Dragon Ball franchise. I chose Dragon Ball because it has a large cast of memorable characters with different personalities, abilities, backgrounds, and roles.

The gallery includes Goku, Vegeta, Krillin, Bulma, and Chi-Chi. I wanted to include both fighters and non-fighters so that the gallery represents more than just the strongest characters in the series.

The design uses a dark background with orange and blue accents inspired by colors commonly associated with Dragon Ball. The character cards are arranged in a responsive grid so that the page remains organized on different screen sizes.

This website was built entirely using HTML and CSS. Because it is a static website, the search bar and character submission form are only visual elements and do not currently process data.
